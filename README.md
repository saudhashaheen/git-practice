# Git Practice

## Article

[From AI Copilots to Agent Swarms — IEEE Spectrum](https://spectrum.ieee.org/amd-agent-swarms)

## Why I Find This Article Interesting

I find this article interesting because it shows how AI could change the **whole process of building software**, beyond helping programmers write code faster. As a computer science student, I’m learning how much work goes into debugging, testing, and reviewing even a small project, so AMD’s idea of AI agents working together on those tasks caught my attention.

I’m especially curious about the possibility of giving agents a goal and having them test several approaches before a human chooses one. It also makes me wonder: **What skills will software engineers need if their work shifts toward defining problems and evaluating AI-generated solutions?**
